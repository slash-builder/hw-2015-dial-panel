# Proposals

Design changes that have been **worked out but not accepted**.

Nothing in this folder is part of the build. `cad/`, `bom/`, `docs/config.txt`
and `docs/wiring.md` remain the only description of what the Dial Panel
actually is. A proposal moves out of this folder when it has sign-off, and at
that point it lands as real CAD, real BOM rows and real build docs — or it is
deleted with a line in the file saying why.

Read a proposal as "here is what this would cost and what it would break,"
not as "here is what to print."
